# The Living Archive — website-ready case study

Upload the entire `living-archive` folder to the root of the `SidneyMagana/sidneymagana.github.io` GitHub repository (keep filenames and folder structure intact). It will appear at `https://sidneymagana.github.io/living-archive/`.

The page links to your existing site's shared logo at `/assets/brand/logo without backround.png`. For local offline preview, the logo will not show, but it will display on the published site.

This package contains 5 optimized WebP stills, 2 original uploaded MP4 motion studies, and a responsive, accessible HTML case study. No existing website files need to be deleted.
